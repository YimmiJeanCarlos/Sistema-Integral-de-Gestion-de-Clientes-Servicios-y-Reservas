# Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto desarrollado en Python utilizando Programación Orientada a Objetos (POO) y manejo avanzado de excepciones para la empresa ficticia Software FJ.

Este sistema permite gestionar clientes, servicios y reservas sin utilizar bases de datos, implementando almacenamiento temporal mediante objetos, listas y archivos de logs.

# Descripción del Proyecto

El sistema fue desarrollado como solución al problema planteado en la Fase 4 del curso de Programación de Ingeniería de Sistemas.

La aplicación permite:

- Registrar clientes
- Gestionar servicios
- Crear reservas
- Cancelar reservas
- Calcular costos
- Manejar errores de manera controlada
- Registrar eventos y errores en archivos logs

Todo el sistema fue construido aplicando principios de Programación Orientada a Objetos y manejo robusto de excepciones.
